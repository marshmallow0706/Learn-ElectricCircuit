# はじめての電気回路 — 回路図が「読める」ようになる教材

回路図を見たことがない人が、**回路図を見て「ああ、これはこういうことをやりたい回路だな」と感じ取れるようになる**ことを目標にした教材です。

数式は最小限です。まず「イメージ」、次に「記号」、最後に「よくある形（定番パターン）」の順で身につけます。

---

## この教材の進め方

1. 章は上から順に読んでください。後ろの章は前の章の言葉を使います。
2. 各章の最後に **演習問題** があります。答えは折りたたんであるので、必ず自分で考えてから開いてください。
3. 1章あたり 15〜25分。全部で 4〜6時間くらいのボリュームです。
4. わからない記号が出てきたら [付録の早見表](ch11-appendix.md) に戻ってください。

> **図が表示されないときは**
> 図は `img/` フォルダの SVG ファイルです。この教材をフォルダごと（`img` フォルダを含めて）ダウンロードして、ブラウザ・VS Code・GitHub などで開いてください。

## 最初に知っておいてほしいこと

回路図は **配線図（実物の配置図）ではありません**。
「どこと、どこが、電気的につながっているか」だけを描いた**地図**です。

だから、

- 線の長さや部品の位置に意味はありません
- 同じ回路でも、人によって描き方が違います
- **形（パターン）を覚えると、一瞬で意味がわかるようになります**

この教材のゴールは、最後のこれです。がんばりましょう。
